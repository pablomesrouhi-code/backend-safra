# 10 — Copy Guidelines (KSA Dialect · Women)

## Language Rules

| Rule | Detail |
|------|--------|
| **Primary** | Arabic RTL — Saudi feminine where possible |
| **Secondary** | English product names as sub-labels only |
| **Dialect** | Light Saudi (تبغين، وش، زين، يعني) — not heavy slang |
| **Formality** | Premium — not street, not corporate MSA only |
| **Pronouns** | Second person feminine singular for ICP (أنتِ · اختاري · ابدئي) |

## Copy Formula (Every Section)

```
1. Hook (emotion / moment she recognizes)
2. Agitate (dignity — not insult)
3. Mechanism (how it works — simple)
4. Proof (study · ingredient · review)
5. CTA (action + price)
```

## Approved Claim Language

| ✅ Use | ❌ Avoid |
|--------|---------|
| يدعم نفساً منعشاً | يعالج رائحة الفم |
| يساعد على امتصاص الرطوبة | يوقف التعرق 100% |
| يساهم في الشعور بالثقة | يشفي · يقضي على |
| تركيبة مطورة للخليج | FDA approved (unless true) |
| بروتوكول 60 يوم | نتائج فورية مضمونة |

## Scarcity Copy (Ethical)

| ✅ | ❌ |
|----|-----|
| "الشحن اليوم للطلبات قبل 4م" | Fake global countdown |
| "متبقي 23 — دفعة هذا الأسبوع" | "Only 1 left!!!" forever |
| "847+ طلب هذا الأسبوع" | Invented millions |

## Trust Microcopy

- "✓ دفع عند الاستلام — ادفعي لما يوصلك"
- "✓ تأكيد عبر واتساب قبل الشحن"
- "✓ تغليف سري · ضمان 14 يوم"
- "✓ شحن 2–4 أيام (SMSA/Aramex)"
